
## 🧠 **16×2 Bit Read Only Memory (ROM) Using Verilog HDL**

### 🔹 Description
This project implements a 16-word, 2-bit wide Read Only Memory (ROM). The contents of the ROM are predefined and can only be read using the address input.

### 🔹 Features
- Fixed memory contents  
- Address-based data output  
- Combinational or synchronous read  
- Lightweight and efficient design  

### 🔹 Applications
- Lookup tables  
- Opcode storage  
- Control signal generation
