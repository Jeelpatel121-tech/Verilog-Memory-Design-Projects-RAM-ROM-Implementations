This repository contains three core memory design projects implemented in Verilog HDL. The goal of these projects is to understand how different memory architectures work at the RTL level and how they are modeled using synthesizable Verilog code.

The designs focus on:

* Efficient memory access
* Read and write control logic
* Address decoding
* Data storage behavior
* Clocked synchronous operations

These projects are ideal for students and beginners in Digital Electronics, VLSI Design, and FPGA-based system development.

### 📌 Verilog Memory Design Projects

#### 📖 Overview

This repository contains Verilog HDL implementations of essential digital memory modules:

* Single Port RAM
* Dual Port RAM
* 16×2 Bit ROM

Each project includes RTL code, a testbench, and is suitable for simulation and synthesis.

---

### 🛠 Tools Used

* Verilog HDL
* EDA Playground / ModelSim / Vivado (any simulator)
* GTKWave for waveform analysis

---

### ▶ How to Run

1. Clone the repository:

```bash
gh repo clone Jeelpatel121-tech/Verilog-Memory-Design-Projects-RAM-ROM-Implementations
```

2. Open the project in a Verilog simulator
3. Compile design and testbench files
4. Run simulation and analyze waveforms
