## 🧠 **Dual Port RAM Using Verilog HDL**

### 🔹 Description
This project demonstrates a Dual Port RAM design where two independent ports allow simultaneous read and write operations. Each port has its own address, data, and control signals.

### 🔹 Features
- Two independent memory ports  
- Simultaneous read/write support  
- Shared memory array  
- Fully synthesizable design  

### 🔹 Applications
- High-speed data transfer systems  
- FIFO buffers  
- Parallel processing architectures
