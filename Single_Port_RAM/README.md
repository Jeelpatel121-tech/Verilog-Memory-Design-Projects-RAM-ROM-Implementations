## 🧠 **Single Port RAM Using Verilog HDL**

### 🔹 Description
This project implements a Single Port Random Access Memory (RAM) using Verilog HDL. The memory supports both read and write operations through a single port, controlled by a clock and write enable signal.

### 🔹 Features
- Synchronous read and write  
- Single address bus  
- Clock-controlled memory access  
- Parameterized memory depth and width  

### 🔹 Applications
- Embedded systems  
- Simple data buffers  
- Control units in digital systems
